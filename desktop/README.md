# Agent Mentor Desktop

Aplicativo desktop residente para o Agent Mentor.

## Instalação

```powershell
cd D:\agent-mentor\desktop
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Execução

```powershell
python app.py
```

## Atalho global

```text
Ctrl + Alt + M
```

## Requisitos

O backend precisa estar rodando em:

```text
http://localhost:8000
```
